# MaxLanding

Telegram-бот и мини-приложение для запуска лендингов: шаблон, свой домен через NS и публичная страница со счётчиком переходов и скачиваний.

## Что внутри

- Бот повторяет меню: создать ленд, домены, примеры, логи, профиль, магазин, панель, поддержка.
- Мини-приложение ведёт по тем же разделам. Если задан `WEBAPP_URL` с `https`, кнопки бота открывают его.
- Домен подключается так: пользователь добавляет имя, у регистратора ставит NS из настроек (`ns1` / `ns2`), сервис проверяет DNS. Админ может подтвердить домен вручную. Если задан IP платформы, подходит и A-запись.
- Магазин продаёт платные шаблоны с баланса.
- Пополнение: CryptoBot, xRocket, USDT TRC20 и TON. Токены и кошельки вводит админ в панели, они хранятся в базе в зашифрованном виде.
- Логи уже пишут переходы, скачивания, оплаты и обращения. Расширенные фильтры оставлены на следующий этап, переключатели IP-хеша, User-Agent и referrer работают.

## Запуск

```bash
cp .env.example .env
npm install
npm run db:setup
npm run dev
```

API: `http://127.0.0.1:8787`. Мини-приложение в разработке: `http://127.0.0.1:5173`.

Локальный вход без Telegram есть только вне production: «Войти как админ» (`telegram id 10000`, баланс 250) и «Войти как пользователь».

Проверка и сборка:

```bash
npm test
npm run build
npm start
```

## Переменные

| Имя | Зачем |
| --- | --- |
| `BOT_TOKEN` | токен BotFather, включает long polling |
| `WEBAPP_URL` | https-адрес мини-приложения для кнопок бота |
| `APP_SECRET` | подпись сессий и шифрование токенов, от 16 символов |
| `ADMIN_TELEGRAM_IDS` | кто становится админом при входе через Telegram |
| `PUBLIC_BASE_URL` | ссылки, которые бот отдаёт на лендинги |
| `DATABASE_URL` | SQLite, файл `data/maxlanding.db` |

В панели управления задаются CryptoBot token (есть флаг testnet), xRocket token и webhook secret, кошельки TON и TRC20, ключи Toncenter и TronGrid, NS и контакт поддержки.

Вебхуки: `POST /api/webhooks/cryptobot` и `POST /api/webhooks/xrocket`. Подпись проверяется до зачисления. Повторный вебхук не удваивает баланс. Кнопка «Проверить оплату» сверяет счёт с провайдером или сетью.

## Домен на своём сервере

Пока NS указывают на хосты из настроек, публичная страница открывается и по `/l/:slug`. Когда DNS совпал, тот же лендинг отдаётся по заголовку `Host`.
